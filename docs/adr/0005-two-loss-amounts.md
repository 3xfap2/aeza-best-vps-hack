# 0005. Две суммы: по прайсу и реально собираемая

**Статус:** принято.

## Контекст
Формула задания — выручка за горизонт × вероятность непродления. Почасовой сервер по прайсу стоит € 4–6 тыс. в месяц (720 часов × цена), но клиент, который за год пополнил счёт на € 3 тыс., столько не заплатит. Эксперт Aéza подтвердил: почасовые тарифы списываются с баланса раз в час.

## Решение
Главная сумма считается по формуле задания. Рядом — реально собираемая: выручка клиента ограничена тем, что он способен заплатить (деньги на счёте или средний платёж в месяц за время жизни). Отдача от удержания считается по второй сумме.

## Последствия
- На демо-наборе: € 8 656 по прайсу и € 1 796 реально.
- Звонок клиенту окупается или нет — решается по реальной сумме, а не по завышенной.
- Деньги во всём коде — целые евроценты, в ответах API — евро, в тексте — один форматтер (`api/app/money.py`).

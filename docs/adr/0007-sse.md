# 0007. SSE вместо WebSocket для живых обновлений

**Статус:** принято.

## Контекст
Панель должна обновляться без перезагрузки, когда пришло событие биллинга или поменялись настройки. Данные идут только от сервера к браузеру.

## Решение
Server-Sent Events: `GET /api/v1/stream` рассылает «пересчитано, версия N» и «отметка по клиенту». Браузер получает сигнал и перечитывает нужные данные обычным REST-запросом.

## Последствия
- Работает через обычный HTTP и nginx (`proxy_buffering off`), браузер сам переподключается после обрыва.
- В событии нет данных — только сигнал, поэтому пропущенное событие не страшно: следующее перечитает актуальное.
- Однонаправленный канал: для команд от панели используется REST.

## Отброшено
WebSocket: двусторонний канал здесь не нужен, а балансировка и переподключение сложнее.
